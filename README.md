# 🎬 BookMyShow Clone

A modern and responsive **BookMyShow Clone** built using **HTML5, CSS3, and JavaScript**. The project provides an intuitive movie ticket booking interface with a clean design, responsive layout, and interactive user experience.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/abhimanyu-tiwari/BookMyShow.git
```

Navigate to the project folder

```bash
cd BookMyShow
```

Open **index.html** in your preferred web browser.
